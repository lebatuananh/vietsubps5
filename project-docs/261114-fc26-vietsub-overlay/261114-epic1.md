## Phương án

**Chọn**: lõi C#/.NET 10 trên Windows (WGC + Windows.Media.Ocr + glossary/cache JSON + Claude Sonnet 5.5) gửi `OverlayFrame` (TCP, JSON-dòng) tới app Kotlin trên Google TV, app vẽ bằng cửa sổ `TYPE_APPLICATION_OVERLAY` + View tự vẽ, font Be Vietnam Pro.
**Lý do**: nhanh nhất để có hình lên TV, không đụng giao thức Remote Play/AGPL ở Epic 1, dễ gỡ lỗi trên laptop, vẫn để ngỏ đường "không cần bật gì" ở Epic 3 (discovery §3.4, R2.3).
**Đánh đổi chấp nhận**: Epic 1 User phải tự mở PS Remote Play trên laptop mỗi buổi; câu mới qua LLM chậm vài giây (làm ấm cache từ fixture).
*(Đã cân nhắc: lõi trên TV — nặng nhất, bắt buộc AGPL, khoá API nằm trong APK; lõi trên điện thoại — vẫn phải mở app mỗi lần. Discovery §3.4.)*
