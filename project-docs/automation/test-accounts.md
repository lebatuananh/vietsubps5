# Tài khoản test

🔴 **Mở file này TRƯỚC khi dựng tài khoản mới.** Dựng xong ⇒ **ghi vào đây ngay**, không để cuối buổi.

Phương pháp: [`workflow/guidelines/automation.md §4`](../../workflow/guidelines/automation.md).

---

**Chưa áp dụng.** Dự án không có backend hay tài khoản ứng dụng riêng.

Tài khoản ngoài duy nhất là **tài khoản PSN của User** (cho Remote Play) — **không ghi ở đây**, không có tài khoản PSN test; mọi thao tác đăng nhập/đăng ký Remote Play do User làm ([CLAUDE.md — Risk gate riêng](../../CLAUDE.md#risk-gate-riêng)).

Khi có đợt thêm tài khoản (vd khoá API của nhà cung cấp dịch cho dev) ⇒ ghi **cách lấy và hạn mức** ở đây, giá trị khoá chỉ ở biến môi trường máy User.
